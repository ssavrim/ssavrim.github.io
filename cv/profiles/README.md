# Profils ciblés

Un profil décrit la manière de présenter la [base commune](../base.md) pour une cible donnée. Il ne duplique pas l'intégralité du CV et n'ajoute aucun fait.

## Profils disponibles

- [`general.md`](general.md) : candidatures spontanées et postes techniques généralistes.
- [`datadome.md`](datadome.md) : candidature Software Engineer — Integrations chez DataDome.

## Ajouter un profil

Créer un fichier Markdown contenant au minimum :

1. la cible ;
2. le titre du CV ;
3. le résumé ;
4. les compétences à mettre en avant ;
5. l'ordre des expériences et réalisations ;
6. les éléments à réduire ou à exclure ;
7. les écarts à traiter avec honnêteté.
